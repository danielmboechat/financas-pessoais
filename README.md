# Financeiro Pessoal — V1

Dashboard financeiro pessoal com dados armazenados localmente no navegador usando IndexedDB.

## Recursos
- Dashboard mensal
- Receitas: salário e outros recebimentos
- Despesas: Alimentação, Saúde, Lazer, Compras, Assinaturas, Educação, Viagens e Outros
- Cadastro de cartões com limite, fechamento e vencimento
- Histórico de lançamentos
- Gráficos
- Exportação/importação de backup JSON

## Privacidade
Os dados cadastrados não são gravados no repositório GitHub. Eles permanecem no armazenamento local do navegador.

## Uso
Abra `index.html` em um navegador moderno. Para publicar, envie os arquivos para um repositório GitHub e ative o GitHub Pages.

## Observação
A biblioteca Chart.js é carregada por CDN na V1. Para uma versão totalmente independente/offline, ela pode ser incorporada ao projeto posteriormente.
